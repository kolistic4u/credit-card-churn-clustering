# Credit Card Customer Churn — K-Means Clustering & Persona Profiling

## 📌 Project Overview
This capstone project explores unsupervised machine learning techniques on a **Credit Card Customer Churn** dataset. Following the **Clustering Depth** track, we apply **K-Means clustering** across multiple values of $K$ (such as $K=3, 5, 7$) to uncover hidden behavioral segments, analyze how customer groupings evolve as granularity increases, and translate the optimal cluster structure into actionable, named customer personas.

---

## 🎯 Key Objectives
* **Multi-K Evaluation:** Run K-Means clustering across three distinct values of $K$ on the same preprocessed dataset.
* **Cluster Evolution Analysis:** Profile the resulting clusters at each value of $K$ and document how customer segments split and refine as $K$ grows.
* **Persona Development:** Select the optimal value of $K$, build at least **three distinct named customer personas**, and extract representative customer records from each cluster to illustrate real-world profiles.

---
